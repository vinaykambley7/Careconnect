# CareConnect - Hospital Information System (HIS)

A modern, clinical-grade Hospital Management System built with **100% Pure HTML5, CSS3, and Vanilla JavaScript**.

## 🚀 Key Highlights
- **Zero Frameworks / No React**: Pure Vanilla HTML, CSS, and JS only.
- **Zero Build Tools**: No npm, no node_modules, no Vite, no webpack.
- **Directly Executable**: Double-click `index.html` to run in any browser, or host on GitHub Pages.
- **Offline & Online Ready**: High-resolution local assets with cloud fallback.

## 🏥 Clinical Workstation Desks
- **Reception / Front Desk**: Patient intake, triage, registration, queue management.
- **Doctor Consultation**: Patient records, vitals examination, diagnoses, digital Rx pad.
- **Pharmacy Dispensary**: Prescription fulfillment, medicine dispensing, inventory status.
- **Operational Analytics**: Real-time hospital metrics, bed occupancy, department reports.
